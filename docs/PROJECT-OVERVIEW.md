# إنفلونسر هَب — نظرة المشروع الشاملة

> مستند مرجعي واحد لفهم النظام كاملًا وتطويره. مبنيّ على فحص المستودع الفعلي (فرع `main`)، لا على تخمين. تُحدَّث أرقامه عند تغيّر البنية.

---

## 1. ما هو النظام

منصّة SaaS متعددة المستأجرين لإدارة التسويق عبر صنّاع المحتوى: من **طلب الحملة** حتى **تسوية المستحقّات** — تربط العميل بالوكالة بصانع المحتوى في مسار تشغيل واحد.

- **عربية أوّلًا · RTL** (مع دعم LTR/الإنجليزية).
- **الحيّ:** `https://influencerhub.io` — نشر مباشر من `main` عبر GitHub Actions → VPS.
- **المصدر والأصل:** مستودع GitHub `digitalalharbi/InfluencerHub-Platform`.

## 3. سلسلة النشر (مهمّة قبل أي تطوير)

```
تعديل محلّي → git push إلى main → GitHub Actions (اختبارات + بناء) → VPS → influencerhub.io
```

> **الدفع إلى `main` = نشر مباشر على الحيّ** (مشروط بـ `ENABLE_VPS_DEPLOY`).
> قاعدة العمل الآمنة: التطوير على فرع `feature/…` → معاينة محلّية → Pull Request → مراجعة → دمج. لا دفع مباشر إلى `main` بلا مراجعة.

**التشغيل المحلّي:**
```bash
cd ~/Developer/InfluencerHub-Platform
composer install && npm install && npm run build
php artisan migrate
php artisan preview:seed-showcase   # بيانات عرض غنية (غير إنتاجي)
php artisan serve --port=8010       # http://127.0.0.1:8010
```

## 6. رحلة الوكالة الأساسية (العمود الفقري)

```
الطلب → الحملة → المخرجات → الترشيح → اعتماد العميل → التعاون → العقد →
المحتوى → مراجعة داخلية → مراجعة العميل → إثبات النشر → الفاتورة →
التحصيل → مستحق المبدع → الاعتماد → الصرف → التقرير → إغلاق الحملة
```

**مبدأ حاكم:** البيانات تنتقل تلقائيًّا ولا تُدخَل مرّتين. موجز الطلب (ميزانية/منصّات/تواريخ/علامة) ينتقل حرفيًّا إلى الحملة عند التحويل، وأتعاب المخرَج تنتقل إلى بند الفاتورة وإلى مستحق المبدع.

## 7. المبادئ الهندسية (تُطبَّق في كل تطوير)

1. **عزل المستأجر fail-closed** — لا يُعتمَد على إخفاء عناصر React؛ المنع في الخادم.
2. **صلاحيات deny-by-default** — سياسات + بوّابات، والفعل المجهول يُرفض. الصلاحيات المالية مفصولة بالفعل (طلب/اعتماد/صرف) مع **فصل الواجبات**.
3. **المال أعداد صحيحة بوحدات صغرى** — لا فاصلة عائمة في دفتر.
4. **الحالة تُشتقّ من الحقيقة** — لا حقل يُضبَط يدويًّا فيناقض الواقع؛ الحالة الافتراضية داخل مسار سير العمل لا خارجه.
5. **لا ادّعاء لما لا نملك** — لا دفع وهمي كحقيقي، ولا تكامل يُعلَن قبل ربط اعتماداته. المصدر الخارجي المفقود = مُحوِّل + بديل + عائق موثّق.
6. **الانتظار يُعلَن لا يُستنتَج** — الحالة التي تنتظر الطرف الآخر تقول ذلك بدل قائمة إجراءات فارغة.
7. **لا صفحة فارغة/جدول فقط** — كل صفحة مساحة تشغيل: مؤشّرات، خطوة تالية، حالات فارغة تشرح السبب.
