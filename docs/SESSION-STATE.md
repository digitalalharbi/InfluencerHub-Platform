## 0. أحدث عمل: طبقة مالك المنصّة (Platform Owner) — P1→P3 مدموجة على main

حساب مالك منصّة **واحد** يشرف على كامل النظام (كل المستأجرين/البوّابات) بلا معرفة كلمات
مرور ولا دخول/خروج متكرّر. مفهوم مستقلّ عن أدوار المستأجرين، خارجيّ، مُدقَّق بالكامل. المرجع
الكامل: `docs/PLATFORM-OWNER.md`.

- **P1 (#77/#78):** علامة مخصّصة `users.is_platform_owner` (محروسة من الإسناد الجماعي)؛
  هرميّة Platform Owner ⊃ System Admin ⊃ Tenant Admin؛ وسيط `EnsurePlatformOwner` + مجموعة
  `/platform`؛ أمر `platform:provision-owner` (يرفض ترقية مستخدم مرتبط بأي مستأجر، يضبط
  العلامتين، لا يطبع كلمة السرّ)؛ **تحديد محاولات الدخول** (لكل بريد+IP، فشل عامّ 429، بلا
  تعداد حسابات)؛ **بلا MFA مُلفَّق** (موثَّق كمستقبل). `PlatformCapabilities` صادقة للشرائح
  المشحونة فقط.
- **P2 (#79/#80):** مبدّل مستأجرين (`/platform/tenants` + تفصيل)؛ بحث خادميّ شامل
  (`/platform/search`) عبر كل الكيانات بلا أسرار؛ ⌘K palette. **إحكام #80:** مصدر أهلية
  بوّابات **واحد** `PlatformPortalEligibilityService` (يعكس الحرّاس، fail-closed، مستأجر من
  الكيان المرجعيّ لا حقل عضوية مكرّر، يتطلّب مستخدمًا نشِطًا، يعيد **كل** السياقات بلا اقتطاع،
  `isContextEligible` للرباعية الدقيقة)؛ قاعدة أهلية المبدع القانونية الوحيدة `portalEligible`
  يستهلكها `EnsureCreator` (صار fail-closed: بلا مؤسسة ⇒ حظر).
- **P3 (#81) — معاينة بوّابة للقراءة فقط:** وسيط `PortalPreview` (`platform_preview:{portal}`)
  قبل كل حارس بوّابة؛ منحة موقَّعة `PlatformPreviewToken` (HMAC، ١٥ دقيقة) تحمل الرباعية
  الدقيقة في `?_pv=`؛ تحقّق توقيع/انتهاء/مالك/بوّابة؛ **قراءة فقط خادميًّا** (`isMethodSafe`)؛
  رباعية دقيقة `isContextEligible`؛ هدف **نشِط**؛ سياق **لمدى الطلب فقط بلا كتابة جلسة**
  (لا `active_client_id`/`active_agency_id` ⇒ متعدّد النوافذ آمن)؛ **هوية مزدوجة** (المالك
  محفوظ قبل `Auth::setUser(target)`، الحرّاس يتخطّون بعلامة `platform_preview`)؛ المالك يختار
  مستخدمًا **حقيقيًّا** مؤهَّلًا من صفحة تفصيل المستأجر؛ بدء/إنهاء مُدقَّقان بالمالك فاعلًا؛
  شريط معاينة + خروج في `AppShell`، والرمز يُمرَّر في روابط `u()`. التقمّص التفاعليّ يبقى P4.
- **P3-hardening (#82) — أربع ثغرات مراجعة أُغلقت:** (١) **سياق دقيق**: مسار البدء يحمل
  `{tenant}/{portal}/{user}/{entity}` (+`?organization=` للوكالة) ويتحقّق بالرباعية قبل إصدار
  المنحة — **بلا first()** نيابةً عن المالك؛ وisContextEligible يرفض org غير-null على بوّابة
  غير الوكالة. (٢) **هوية مزدوجة مُحكمة النطاق**: `Auth::setUser(الهدف)` داخل try/finally يعيد
  المالك عند فكّ المكدّس. (٣) **تكافؤ سياق حقيقي**: حلّالات واحدة `app/Http/Portal/*Resolver`
  يستهلكها الحارس **والمعاينة** — تُعيد كل الخصائص/المشاركات (activeClient/clientMembership/
  myClients/clientUnread/activeAgency/partnerMembership/myAgencies/creator) بلا كتابة جلسة.
  (٤) **حظر التحوّر في كل مكان**: حارس عالميّ `PlatformPreviewGuard` يردّ 403 لأي طلب غير آمن
  يحمل منحة (يشمل logout/switch خارج مجموعات البوّابات)؛ معترِض inertia يُلحق `_pv` بكل طلب لا
  u() فقط؛ الواجهة تستبدل الخروج بـ«الخروج من المعاينة». **دلالة الإنهاء موثّقة**: تنقّل فقط +
  تدقيق بفحص المالك؛ المنحة تبقى صالحة حتّى انتهائها (١٥د) — مقبول لأن المعاينة قراءة بحتة،
  والإبطال الفوري يأتي مع P4/P5.
  مصفوفة أمان `tests/Feature/PlatformPreviewTest.php` (٢٣ اختبارًا) + الحزمة كاملة خضراء.
- **جولة قبول P3 (متصفّح + خصوصية + قابلية توسّع) قبل الاعتماد:** (أ) مواصفتا Playwright حقيقيّتان
  عبر Chromium/Firefox/WebKit: `19-platform-preview` (رحلة كاملة بالواجهة: دخول المالك → مستأجر →
  سياق دقيق → «معاينة» → بوّابة حقيقية + شريط + هوية الهدف → تنقّل يُبقي المعاينة → زرّ تحوّر حقيقيّ →
  الخادم 403 → جلسة المالك سليمة → خروج) و`20-preview-multitab` (تبويبان بسياقين يبقيان مستقلّين).
  (ب) تدقيق أسطح التحوّر: كل طفرات البوّابات عبر Inertia فتحمل `_pv`؛ لا axios ولا نماذج POST أصليّة؛
  والحارس العالميّ صار **قبل** SubstituteBindings فيَردّ 403 قبل الربط (يشمل الخروج/التبديل).
  (ج) `PlatformPreviewPrivacyTest`: سِنتينلات **مزروعة فعلًا** (أجر/مستحقّ/بنك المبدع مقابل سعر بيع
  العميل) تُثبت صفر تسرّب ماليّ متبادَل وصفر تسرّب اعتماد، مع فحص إيجابيّ أن السِنتينل يظهر في جانبه.
  (د) قابلية التوسّع: سقف ٢٥ أُزيل — مُنتقٍ خادميّ قابل للبحث والتصفيح (اسم/بريد/كيان) يبلغ أيّ سياق؛
  اختبار >٢٥ سياقًا يُثبت اكتشاف #٢٦ ومعاينته. الخلفية ١٣٣١ خضراء + Chromium E2E كامل أخضر.

**التالي:** P4 (تقمّص تفاعليّ مؤقّت قابل للإبطال + شريط سياق المالك + أعمدة تدقيق
`acting_as_user_id`…) — منفصل تمامًا. ثم P5 (تصليب متعدّد النوافذ/أمن) وP6 (تحقّق إنتاج).

## 3. القيود المطبَّقة (مهمّة — لا تُخالَف)

- **بيانات المصدر حسّاسة (ملكية فكرية):** استُبعِد نهائيًّا ولا يُذكَر: اسم المصدر/العلامة، رقم الترخيص، البنك/IBAN، اسم الموظّف، الشحنات. حارس `ALLOWED` في الاستيراد + اختبار يثبت عدم التسرّب.
- **لا PII في git إطلاقًا:** الجوّالات (~٣٠٠٠) في `storage/app/private/pool/pool.json` (مُتجاهَل)، والـExcel لا يُنسَخ للمستودع. الاستيراد يقرأ ملفًّا منظَّفًا خارج git.
- **لمدير النظام وحده:** كل المسارات محميّة بوسيط `system_admin`. لا تظهر لوكالة/مبدع/عميل.
- **التمييز المقصود:** مدير النظام يرى كل بيانات الحجز (تواصل، تكلفة، بيع). التحويل إلى العميل يأخذ **نسخة بلا جوّال** (snapshot لا مرجع) تصمد لحذف القاعدة.
- **زرّ الحذف الكامل:** يمسح القاعدة وملفّ الاستيراد بتأكيد نصّي، قبل أي استعراض للنظام.
- **لا ذكاء مُلفَّق:** `OpenAiAssistant` معطّل بصدق بلا مفتاح، يرتدّ إلى القواعد.

## 5. ما لم يُنفَّذ بعد (قرار المالك)

1. ✅ **منطق OpenAI الفعلي** — أُنجز: `OpenAiAssistant::interpret()` يستدعي Chat Completions (وضع JSON) لاستخراج المعايير (platform/categories/min_followers/budget_riyals) مع `sanitize` وتحقّق، وارتداد صادق للقواعد عند أي تعذّر (سائق موسوم بصدق)، وشبكة أمان بالقواعد عند استخراج فارغ. يُفعَّل بـ`POOL_ASSISTANT_DRIVER=openai` + `OPENAI_API_KEY` (والموديل/الرابط/المهلة قابلة للضبط في `config/services.php`). ٥ اختبارات تُحاكي HTTP (تحليل، تنقية، ارتداد الخطأ، شبكة الأمان، تكامل الصفحة). لا يتغيّر المتحكّم ولا الصفحة.
2. ✅ **واجهة قبول/رفض التوصية في بوابة العميل** — أُنجزت: `Inertia/Client/RecommendationController` + `ClientPortal/Recommendations/Index.tsx` + مساران تحت `/beta/client/recommendations` + عنصر تنقّل بشارة حيّة (`client_recommendations` في `NavigationBadges`، للعميل النشِط فقط). ٦ اختبارات (تشمل حارس عدم تسريب الجوّال). محقّق حيًّا: اعتماد/رفض يحدّثان الحالة والشارة.
3. **الدفع إلى `main` والنشر** — لم يحدث. البيانات لن تصل الحيّ عبر Claude (لا PII في git)؛ تُشغَّل `pool:import` على الخادم بملفّ يضعه المالك.
4. **رحلة الوكالة الأساسية** موقوفة عند قرار العميل على ترشيح الحملة (سياق أقدم — انظر أقسام CONTINUATION-STATE السابقة).

**ملاحظة محلّية:** لتجربة بوابة العميل ضُبطت كلمة مرور `client@a.test` إلى `client-local-1234` وأُنشئت ٦ توصيات تجريبية للعميل 1 (بيانات محلّية فقط، لا تدخل git).
